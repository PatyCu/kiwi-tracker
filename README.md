# Kiwi Tracker

A mobile-first pet care and health tracker for iOS and web.

> Status: prototype

## Prerequisites

- Node.js 22
- npm 10
- Xcode and an iOS Simulator for iOS development

## Setup

```bash
npm ci
```

## Run

```bash
npm run ios
npm run web
```

## Validate

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
```
