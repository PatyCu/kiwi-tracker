# Kiwi Tracker

A mobile-first pet care and health tracker for iOS and web.

> Status: prototype

## Prerequisites

- Node.js 22
- npm 10
- Xcode and an iOS Simulator for iOS development

## Install

```bash
npm ci
```

## Develop

```bash
npm start
```

From the Expo terminal, press `w` to open the web app or `i` to open the iOS Simulator.

## Validate

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
```
